FAQ

Questions fréquentes

Tout ce qu'il faut savoir avant de commencer.

Comment fonctionne le paiement ?

Le site redirige vers une page Stripe hébergée. Aucune donnée de carte bancaire n’est enregistrée ou traitée par GitHub Pages.

Puis-je lire les e-books sur mon téléphone ?

Oui. Le design prévoit des fichiers PDF lisibles sur mobile, tablette et ordinateur.

Les e-books conviennent-ils aux débutants ?

Oui. Le contenu est présenté de manière progressive et orientée action.

Où mettre mes liens Stripe ?

Ajoute uniquement les URLs publiques Stripe Payment Link dans payment-config.js. Ne publie jamais de clé secrète Stripe dans GitHub.
